# Honesty, copy, and voice (motion context)

Full voice rules: website brief §8. This file is what motion/mock agents need at a glance.

## Honesty (LOCKED)

- Tag every mock: mono **ILLUSTRATION ONLY**, **Illustration**, or **Example** (match live site pattern).
- No fabricated logos, testimonials, stats, user counts, awards, or certification badges.
- Eval scores: use **pass/fail** or modest plausible values, always tagged illustration.
- Timestamps like “ran 2 min ago” are fictional scene dressing, not live data claims.
- Placeholders: `[CERTIFICATION PLACEHOLDER]`, `[RESULT TBC]`, etc. — do not replace with invented facts.

## Voice

- UK English (optimise, organisation, colour, programme).
- Solution-aware: never diagnose the reader’s problem on the page.
- No em dashes — commas, full stops, colons.
- No hype: revolutionary, game-changing, cutting-edge, unleash, supercharge, 10x.
- No public prices: “fixed price”, “monthly per agent”.
- “real-time” (adjective) vs “real time” (noun).

## Locked lines (do not paraphrase in buyer UI)

- Ownership: “You own your data, processes and outputs. We host, run and improve the agents.”
- Promise: “Live in 10 working days\*” + footnote on access, data, written scope.
- Product names: **10-Day Agent Build**, **Agent Care** (never “Run” as product).

## Kill list

Never on buyer surfaces — see brief §8.3 and [ban-list.md](ban-list.md). Includes Profit Constraint Score, profit leak language, Profit Engine as product, binding constraint diagnostics, retired webinar funnels.
